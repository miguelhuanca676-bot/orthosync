# Modelos de la CNN

Copia aquí el contenido de `modelos/servidor/` del zip que genera el cuaderno de Kaggle:

```
info.json  tumor.onnx  malignidad.onnx  hueso.onnx  aspecto.onnx  detector.onnx
```

Esta carpeta no se sube a GitHub (los modelos pesan mucho). Sin modelos el sistema funciona igual:
los estudios se guardan con estado «sin modelos» y se pueden analizar después.
